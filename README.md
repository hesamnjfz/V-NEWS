# V News Network

Independent news network website — live coverage, top stories, investigations, and global desks.

**Tagline:** Clarity in a noisy world.

## Stack

- Next.js 16 (App Router, static export)
- Tailwind CSS v4
- Framer Motion
- TypeScript

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

Static output is written to `out/`.

## Sections

- **Hero** — Brand-first full-bleed lead with breaking ticker
- **Top Stories** — Editorially prioritized coverage
- **World / Politics** — Desk sections
- **Investigations** — Long-form special projects
- **Live** — Broadcast schedule and watch surface
- **Network** — Mission, scale, and bureaus
- **Newsletter** — Morning briefing signup
